# 骏河屋搜索匹配规则-实测（2026-10-11）

从你电脑直连 `https://www.suruga-ya.jp/search?search_word=…` 实测（家用网络不被拦，机房 IP 才会 403）。

## 规则

1. **按空格（和符号）拆词，每个词都必须出现，少一个就 0 件。**
   - `WHITE ALBUM2 ぬいぐるみ` 2 件 → 加上 `小木曽雪菜` 变 0 件。
   - `高木さん パーカー` 3 件 → `高木さん からかいパーカー グレー Lサイズ` 1 件。
2. **符号当分隔符，不影响结果。** `「WHITE ALBUM2」小木曽雪菜＆冬馬かずさ` 和用空格分开一样，都是 28 件。
3. **全角半角、大小写不影响。** `ＷＨＩＴＥ ＡＬＢＵＭ２`、`white album2` 都和 `WHITE ALBUM2` 一样。
4. **词的一部分也能匹配上。** `エミリア ぬいぐる` 19 件；`エミリ ぬいぐるみ` 会混进「エミリー」。
5. **两个词连在一起写就配不上。** `WHITEALBUM2 小木曽雪菜` 0 件。
6. **常见简称能搜到。** `リゼロ` / `Reゼロ` / `Re：ゼロから始める異世界生活` 搭配 `エミリア ぬいぐるみ` 都是 22 件；`冴えカノ A3プリモアート` 4 件。
7. **商品标题的写法**一般是：`角色名 商品名 「作品名」 活动/限定`。商品名里的修饰词（ふわかわ、ロリータ、颜色、尺码）经常不在标题里。

## 对现有 0 件档案的核对

| 档案搜索词 | 逐步放宽的结果 | 结论 |
|---|---|---|

| 高木さん からかいパーカー グレー Lサイズ | 1 件 → `高木さん パーカー` 3 件 | 写长了会漏掉其他颜色和尺码 |

## 建议的搜索词写法

- 骏河屋只用 **作品名或简称 + 角色名 + 品类** 这两三个词。颜色、尺码、版本、活动名、修饰词都不放进搜索词，交给后面的匹配和 AI 判定去筛。
- 词与词之间一定要空格分开，不要连写。
- 代价：搜索词写宽了，搜到的商品会变多，AI 判定要多看一些。现在机房 IP 直连骏河屋会被 403，要走备用通道（Firecrawl / Browser Run），**多加一个搜索词就多一次付费抓取**，所以要改的是那一个搜索词本身，不要给每个档案多加几个备选搜索词。
