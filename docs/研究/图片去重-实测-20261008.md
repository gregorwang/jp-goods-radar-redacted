## 结论

1. **图片去重做得成，而且比标题去重强得多。** 赛车初音基线 1008 件：标题去重后 879 张卡，图片去重后 622 张；
   鸣濑白羽基线 872 件：750 → 634。同一款 Muchute 景品 64 件合成 1 张卡（标题去重只能合掉一小部分）。
2. **只靠"图片像不像"不够准，必须四步配合**（第 1 轮只用图片，用户标出 7 组错；第 2 轮四步配合后用户考卷 0 错）：
   ① 图片指纹提名 → ② 标题里写明的区别否决 → ③ 多件合拍的照片不参与 → ④ 细节比对复核。
   分工原则和 AGENTS.md §4 一致：**标题里写着的区别是确定的，代码做厚；图片像不像是概率，只负责提名。**
3. **原则：宁可少合，不能合错。** 少合 = 用户多看一张卡；合错 = 一件不同的商品被藏进折叠里。所有门槛按这个方向定。
4. **成本可以忽略。** 两轮实验（含失败重跑、首次下载模型）Modal 共 $1.68；正式上线每天只处理新上架的几十到一百来件，估计每天几美分。
   最贵的是"看图判断多件"那一步（7B 看图模型，A10G）。
5. **不该用"以图搜图"**：以图搜图是拿一张找像的，去重是一堆图自己分组，任务不同；也不该依赖 jp-market-databricks 的服务（用户 10-08 否决）。

## 四步的具体做法和实测数字

**① 图片指纹提名**：DINOv2-large（看长相）+ SigLIP-so400m（看是什么）两个指纹取平均。
- 只用"看长相"的那个，Muchute 每件最像的 10 张里 96.7% 是同款；两个合用 97.4%。
- **图片不能裁边**：模型默认裁掉四周再缩成 224，盒子边上的字会丢。改成补白成正方形、448 分辨率后，同样考卷全对，还多合并了 24 张卡。
- 按相似度分层聚类（average linkage）：手办门槛 0.75；扁平周边（吧唧、亚克力、色纸、卡、海报）门槛 0.88。
  扁平周边形状版式都一样，区别全在画面，只用 0.75 时合错最多（61 组里约 25～30 组有问题）。

**② 标题否决**（`experiments/image-dedup/titlerules.py`）：两件都写了同一类标识，而且对不上，就拆开。
- 年份；款式字母 (A)～(Z)；①②；Rd.N；Type X；キービジュアル N；比例 1/N；粘土人 / figma 编号；
- 厂商（セガ、タイトー、フリュー、バンプレスト、グッスマ、FREEing……）；商品线（ムチュート、ハイグレード、プレミアム、ESPRESTO、POP UP PARADE……）；
- 版本名：紧挨 Ver 的词（セパン、SPA、応援、Tropical……）。**只有两边都写了具体版本名才算冲突**——卖家常省略版本名，
  「Racing Miku 2025ver」和「SPA 2025Ver.」用户认可是同款；
- 写了比例的 vs 景品线 / 粘土人 / figma / POP UP PARADE（都没有比例）→ 不可能是同一件；
- **周边种类**：挂画 / 文件夹 / 卡套 / 色纸 / 亚克力 / 桌垫 / T 恤……不同就拆。**这是二次元周边特有的坑**：同一张插画会印在好几种周边上，图片必然很像（白羽实例：挂画和透明文件夹被合在一起）；
- 拆分时，没写某类标识的那件分去**图片最像**的那一份（最初按顺序分，把没写厂商的セガ景品分进了 FREEing 那份）。
- 标题本身说明是多件的（两个年份、两条商品线）→ 当打包，不参与合并。

- **第 3 轮补的（10-09）**：版本名允许平假名（「ちょこぷに Ver.」）；KV1；「スポンサー特典」；figma SP-NNN；
  骏河屋格式「N.角色名(款式) 「系列名」」里的编号、款式、**结尾的**系列名。系列名只认标题最后那个「」——
  一开始认所有「」，结果「未使用品」「ほぼ新品」这种品相写法把 15 组真同款拆散了。

**③ 多件合拍照片**：Qwen2.5-VL-7B 逐张判断"这张照片里是不是拍了不止一件**不同**的商品"。
- 用户标的 6 张多件照片全部抓到；也抓到了标题没写打包的（白羽 #252 一堆周边、#172 两张色纸）。
- **已知误判**：亚克力立牌 + 它自己的底座、官方图里立牌 + 附赠卡，会被当成两件；提示词改了两次没改过来。后果是少合，不会合错。
- 初音 197/1008、白羽 200/872 张被判多件，偏多。

**④ 细节比对**：DISK 特征点 + LightGlue 匹配 + MAGSAC 几何校验，数两张图上能一一对上的细节点。
- 考卷上：**真同款的中位数 379 点、九成在 237 以上；不同款最多 55 点**，中间空着一大段，门槛定 100。
- 组内两件"连得上" = 细节点 ≥100，或整体相似度 ≥0.95（0.9 太松：两顶不同的帽子细节点只有 19，靠 0.91 的整体相似混进来过）。按连通块拆组。
- 管不了多件合拍：#293 照片里确实有一个一模一样的盒子，细节点 250～390。这类只能靠 ③。

**白羽额外暴露的：店铺"NO IMAGE"占位图。** 乐天上骏河屋系店铺没图时统一用一张占位图，桌垫、贴纸、卡牌、小说被合成一组。
规则：几张图几乎一模一样（≥0.98）但标题互不相干（字面重合中位数 <25%）→ 占位图；和已认定占位图一模一样的也算。白羽认出 41 张，全对；初音 0 张。

## 下一个用途：精确同款雷达按参考图找货（用户 10-09 提出，另开会话研究）

**用户的设想**：建精确同款雷达时，用户给一两张"我要找的那件"的照片；雷达每天巡回，拿每件新上架商品的图和参考图比。

**用户定的规则（10-09）：图像命中就推，标题命中也推，两条路互不否定。**
- 图片识别的准确率很高（初音近千件，用户只挑出几处错），**优先级不低于标题**——不少卖家的标题是乱写的。
- 标题没对上，不能否掉图片的命中；图片不像，也不能否掉标题的命中。
- 注意和去重的区别：去重里标题可以否决图片（宁可少合，代价只是多一张卡）；找货里漏一件就是一件绝版货没了（AGENTS.md §4），所以两条路取并集。

**为什么图片不像也不能否决——初音 #563 / #567**：标题一字不差、确实同款（粘土人 レーシングミク 2016 个人赞助特典），
但一张实拍手里没拿旗子，一张官图拿着旗子。**只看图片它们不像。**参考图是官图、卖家拍实物（或配件没装）时，图片路径会漏，要靠标题路径接住。
- 参考图最好一张官图 + 一张实拍；只给一张时提示"多给一张能少漏"。
- 实拍 vs 官图、配件装没装、盒装 vs 拆盒，是通用模型最弱的地方，也是以后微调最该补的（见 [长期研究/二次元周边视觉模型.md](../长期研究/二次元周边视觉模型.md)）。
