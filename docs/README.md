# 文档索引

> 2026-10-08 整理，10-09 加了 长期研究/、成本/。文档按"现在还要不要看"分成七个文件夹，**新文档也按这个放**：
>
> - **常用/**：长期有效、随系统更新的说明和手册。出问题、接手项目先看这里。
> - **成本/**：花多少钱、单价、开关。新功能动手前先在这里算账，实测出新数字就补。
> - **研究/**：带数据的调查和评估。结论可能过时，看日期；新数据就往原文档里补。
> - **长期研究/**：要攒几个月甚至一两年的事（数据积累、模型训练）。可能很久不动，但不能丢；每篇开头写清"上次停在哪、下次从哪接"。
> - **待验证/**：代码已上线、但还没在线上真跑通的。写清验什么、怎么查、什么结果算过；验完挪进 归档/。（10-11 加）
> - **进行中/**：还有没做完的事的交接和任务清单。做完就挪进 归档/。
> - **归档/**：已做完、或已被新文档取代的。只在追查"当时为什么这么改"时翻。
>
> 文件名末尾的日期是写的那天，不是最后更新的那天。
>
