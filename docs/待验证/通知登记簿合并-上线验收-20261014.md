## 查数

```sql
-- 最近的发送记录：每个渠道一行
select n.updated_at, n.channel, n.status, n.outcome, n.attempts,
       left(coalesce(n.fallback_reason, n.outcome_error, n.last_error, ''), 60) why,
       p.name, coalesce(e.semantic_event_type, e.event_type) type, e.status ev
from radar_core.notice_deliveries n join radar_core.events e on e.id = n.event_id
left join radar_core.watch_profiles p on p.id = e.watch_profile_id
order by n.updated_at desc limit 20;

-- 还没终结的（正常应该只有几条在路上的；53 条 hermes failed 是 8 月微信停用前留下的，不会再动）
select channel, status, count(*) from radar_core.notice_deliveries
where status in ('pending', 'sending', 'failed') group by 1, 2;
```
