## 1. 用户定下的规则

- **一件通知怎么发，全由它所在档案的设置决定**，不在推送页、邮件模块里另立全局规矩（AGENTS.md §4「送达门槛每档案一个设置」同一思路）。
- 两个开关，不是三选一：**两个都关 = 只巡回、不通知**（有些档案只想攒数据）。
- 只开飞书、飞书没送到 → 邮件兜底；飞书下一轮好了就不再发邮件（每一轮各自判断，没有要记的状态）。
- 「飞书」= 群 webhook 为主，飞书应用私聊备用（私聊那摊 10-14 被封着）。判断「送到没有」看群加私聊，哪一处收到都算。
- 管所有档案：关键词、精确同款雷达、降价（单品）。
- 默认：原来在推送名单里的 4 个关键词档案邮件 + 飞书；其余所有档案、以后新建的只发邮件。
- 推送页每个群「收哪些档案」保留，按关键词 / 精确同款 / 降价分组；**没开飞书的档案灰着、点不了**，勾选保留。
- 档案开了飞书、却没有群收它、私聊也没开 → 当作没送到改发邮件，档案页上标红提示去「推送」页勾群。

## 4. 已知的、故意没做的

- **邮件量**：4 个关键词档案邮件 + 飞书时一天约 70～80 封日报邮件，贴着 `MAX_EMAILS_PER_DAY=80`；到线后当天的降价、精确同款会被折进汇总、第二天才发。上线时已告诉用户，嫌多就在档案页关邮件（只发飞书，没送到自动补邮件）。
- 精确同款周报、来源故障提醒不归档案开关管，照发邮件。
- 飞书卡片上精确同款、降价**没有按钮**（「不想看」写的是关键词日报标注，对它们不适用）。
- 建档回执、单品盯完了：飞书没有卡片，只开飞书也照发邮件。
- 私聊被封期间，每轮私聊都会失败一次（不花额度）；群收到了就算送到，不会触发邮件。
