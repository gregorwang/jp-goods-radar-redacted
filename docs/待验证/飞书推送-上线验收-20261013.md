# 飞书推送 · 上线验收（2026-10-13）

> **一句话**：每小时巡回的新货，除了照旧推安卓 App，再合成一张带九宫格图的飞书卡片私聊发给你。10-13 上线，已经在线上跑通发送（第 4 节）；按钮和额度还要再用几天才算验完。
> 入口和开关、凭证位置见 `docs/常用/自用推送渠道-总览.md`。**10-13 你决定停用安卓 App（手机端停），飞书接替。**
> 验完挪进 `docs/归档/`。

## 1. 现在的样子

- 每小时 4 个 IP 合成**一条**消息：最后一条推送进来后安静 90 秒、最多等 6 分钟就发。11:20 那一轮实测：3 个 IP 合成 1 条，花了 4 次额度（3 张拼图 + 1 条消息）。
- 每个 IP 一节：小标题 → **一张九宫格图** → 每件一行。
  - 拼图：**永远一行 3 格**、格子一样大（只有 1 件也只占 1/3 宽）；每格左上靛蓝序号、左下价格条（低于同款行情绿色、拍卖橙色带「拍」、其余深灰）；点开能放大。
  - 每行：靛蓝序号小块（和图上同色，一眼对上）、标题（点了打开商品页）、灰色一行写来源中文短名（煤炉 / 雅虎拍卖 / 雅虎闲置 / 骏河屋…）、上架时间（不是当天的带日期）、拍卖的出价次数和截止时间、同款行情；右边价格和「不想看」「等降价」。
- 「不想看」写 `digest_item_labels`，和 App 标注同一张表，排除词总结流程不变；再点一次撤销。
- 「等降价」和 App 同一套（单品档案，降价发邮件，同时在盯上限 30 件）。
- 一小时超过 20 件拆成几张卡（第 1/2 张……）。
- 私聊口令：「状态」「样卡」「暂停」「恢复」；单聊菜单配了状态 / 样卡 / 暂停推送。
- **App 一点没动**，两路并行。飞书出错不影响 App 和 collector。
- **群（10-13 下午加）**：同一张卡**再用群自定义机器人（webhook）发一份到群里**。webhook 发消息**不算 API 额度**；图片用你那一路已经上传的 `image_key`（同一租户，10-13 实测 webhook 接受应用传的图），所以发群一次额度都不多花。
  群里的卡没有「不想看」「等降价」（webhook 卡片按钮不能回传），点标题跳商品页。`FEISHU_WEBHOOK_IMAGES="0"`（wrangler.jsonc）就是纯标题版。
  群只在第一次尝试时发，重试只补你的私聊，免得群里重复。地址和签名密钥是 secret `FEISHU_WEBHOOK_URL` / `FEISHU_WEBHOOK_SECRET`，`GET /feishu/status` 的 `webhook.last` 看最后一次成没成。
  群里 @ 机器人仍然没有反应（那是应用机器人的事，见第 6 节）。

## 2. 额度（硬约束）

租户是飞书基础免费版，**每月 1 万次**（用户 10-13 在后台确认）。现在的做法约 2,400 次 / 月；到 8,000 次自动只发文字、9,600 次停发，北京时间每月 1 号归零。
同一张拼图只传一次（按格子内容 + 拼法版本号缓存 `image_key`）；失败最多重试 3 次。10-13 调试花了约 50 次。

## 3. 代码和配置

| 文件 | 做什么 |
|---|---|
| `apps/push-relay/src/feishu/desk.ts` | 排队、定时发送、额度记账、私聊口令、菜单、按钮回调 |
| `apps/push-relay/src/feishu/card.ts` | 卡片长什么样（**改 UI 改这里**） |
| `apps/push-relay/src/feishu/batch.ts` | 几条推送合成卡片、拆卡 |
| `apps/push-relay/src/feishu/grid-image.ts` | 九宫格图；各来源图片换 JPEG 地址；改拼法要把 `GRID_LAYOUT_VERSION` 加一 |
| `apps/push-relay/src/feishu/api.ts` / `crypto.ts` | 飞书接口；事件解密验签 |
| `apps/push-relay/src/index.ts` | `POST /feishu`（事件 + 回调）、`POST /feishu/sample`、`POST /feishu/ping`、`GET /feishu/status` |
| `apps/collector/src/push-delivery.ts` | 推送消息里多带 `digestEventId`（「不想看」要用）。随 git push 由 Workers Builds 发布 |

- push-relay **手动发布**：`pnpm --filter @jpgr/push-relay run deploy`（不在 Workers Builds 里）。
- 飞书事件 / 回调地址：`https://push.example.com/feishu`（push.example.com）。**不能用 workers.dev**，大陆被墙。App 仍连 workers.dev。
- secret（都已配，本机副本 `~/.jpgr/feishu-app.env`）：`FEISHU_APP_SECRET`、`FEISHU_VERIFICATION_TOKEN`、`FEISHU_ENCRYPT_KEY`；`FEISHU_APP_ID` 写在 wrangler.jsonc。
- 收件地址：你的私聊会话号 `chat_id`（oc_ 开头），从你发来的消息事件里记下，存在 DO 的 meta 里。**按 open_id 私发会被拒成 230101**。
- 飞书后台：应用「JRPG小时级商品数据推送」，权限 `im:message:send_as_bot`、`im:resource`、`im:message.p2p_msg:readonly`；事件「接收消息」「机器人自定义菜单事件」；回调「卡片回传交互」；菜单事件 ID `status` / `sample` / `pause`。

查状态（口令在 `apps/android-push/local.properties` 的 `jpgr.push.deviceToken`）：

```bash
curl -H "Authorization: Bearer <token>" https://push.example.com/feishu/status            # 开没开、本月用了几次、队列
curl -X POST -H "Authorization: Bearer <token>" https://push.example.com/feishu/ping      # 发一张状态卡，失败直接返回飞书的报错
```

实时日志：`cd apps/push-relay && npx wrangler tail`。事件名：`feishu_digest_sent`、`feishu_card_failed`（带飞书错误码）、`feishu_grid_failed`、`feishu_digest_dropped`、`feishu_web_call_failed`。

## 4. 验收清单（10-13 收工时）

| # | 验什么 | 怎么查 | 结果 |
|---|---|---|---|
| 1 | 绑定接收人 | 私聊发一句话 | ✅ 状态卡收到；`ownerBound`、`ownerChatId` 都有 |
| 2 | 样卡 | 状态卡「发一张样卡」 | ✅ 收到，图上序号和列表对得上（第一版 UI 被嫌难读，已改成第 1 节的样子） |
| 3 | 真推送 | 整点 20 分那一轮 | ✅ 11:20 那轮 3 个 IP 合成 1 条发出（日志 + 额度对得上）；**你还没回看这张卡** |
| 4 | 不想看 | 点某一行「不想看」 | ⏳ 11:20 起的卡才有这个按钮（之前的推送没带日报编号）。过：行变灰划线、按钮变「撤销」；`digest_item_labels` 多一条 hide；App 标注页这件也是「不想看」 |
| 5 | 撤销 | 再点「撤销」 | ⏳ 行恢复；表里那条删掉 |
| 6 | 等降价 | 点非拍卖商品的「等降价」 | ⏳ 按钮变「在盯降价」；主站出现单品档案 |
| 7 | 暂停 / 恢复 | 状态卡按钮或私聊「暂停」「恢复」 | ⏳ 暂停期间整点不来卡片，App 照常 |
| 8 | 额度 | 10-14 看 `quotaUsed` | ⏳ 一天 80 次左右；明显多就查 |
| 10 | 群 webhook | 样卡 / 整点那轮 | ⏳ 发送成功（`webhook.last.ok`），**等你确认群里的图显示出来了** |
| 9 | 图片下载 | 卡片里有没有灰色占位格 | ✅ 样卡里煤炉、雅虎拍卖的图都正常（Cloudflare 出口能下） |

## 5. 已知没做的

- 卖掉了在原卡片上标「已售出」：每改一次算一次额度，先不做。
- 加急提醒：要按档案设阈值，先看用法再说。
- App 停不停：并行跑几天，你觉得飞书够用再决定。
- 列表太长怎么办（一小时几十件时）：可以每个 IP 只列前几件、其余折叠，等你用几天再说。

## 6. 推到群（没做）

用户 10-13 问过群里能不能推，答复是"现在只推私聊"。要做时：
1. 权限加 `im:message.group_at_msg:readonly`（读群里 @ 机器人的消息），事件「接收消息」已订、不用改。
2. 群里 @ 机器人说「推送到这里」→ 记下这个群的 `chat_id` 作为收件地址（或同时发私聊和群；图片 `image_key` 可共用，多花的只是发消息，每月约 +600 次）。
3. **先想清楚谁能点按钮**：现在只认你的 open_id，别人点会提示「只有你能操作」。
