# 屏蔽单品 + 最低价 · 交接（2026-10-09）

## 起因

10-09 赛车初音日报 179 件，用户浏览一遍要五六分钟。用户逐件标了一遍（不想看 76 / 想看 89 / 没标 14），
"不想看"里六成是三件商品反复出现：

| 商品 | 一封里出现 |
|---|---|
| SPA 2025 景品手办（GiGO 限定 ハイグレードフィギュア） | 约 30 次 |
| Muchute 2025 セパン 景品 | 约 8 次 |
| 2019 粘土人橡胶挂件（乐天一家店，¥498） | 7 次 |

根因：日报按链接去重，景品 / 一番赏每天有新卖家挂出来，换个卖家就是新链接。爱蜜莉雅的一番赏奖品同理。
排除词治不了：同一件商品标题写法七八种，单个词命中就挡又会误伤。

## 做了什么

1. **屏蔽单品**（`packages/core/src/muted-products.ts`）
   一条屏蔽 = 几个词组，标题里**每组都命中**才算这件商品，组内 `|` 写别名。只比标题，不比店名卖家名。
   - 表：`radar_core.watch_profile_muted_products`（迁移 `20261009210000_watch_profile_muted_products`）
   - 采集侧：在 AI 之前挡掉，观察记录 `rejected`，理由「你屏蔽了这件商品（SPA / ハイグレードフィギュア + 2025）」
   - 日报组装：再按标题过一遍，今天刚屏蔽的当天日报里就没有
   - 后台：`/watches/<档案>/muted-products`。从邮件点进来带着那件商品，标题切成词点选；
     **保存前预演**过去 30 天会挡掉哪些（和采集侧同一个匹配函数）；已屏蔽列表可撤销
   - ~~邮件里每件商品「不再推这件 ›」~~：当天就删了（用户：邮件只用来看，不能从邮件跳进私人后台）。
     入口改为后台档案页的「屏蔽单品」按钮，以及下面的「日报标注」页
2. **最低价**（`watch_profiles.min_listing_price`）
   档案级的送达门槛，**不是搜索条件**：不传给来源。原因：改各来源的搜索设置会触发重新建档
   （`keywordBaselineResetStatements`），再发一封上千件的回执。改最低价不重置基线。
   拍卖按当前出价比，价格缺失的不挡。后台在档案的「关键词雷达共同规则」里。

3. **日报标注页**（后台侧栏「日报标注」，`/digest-labels`）
   选档案、选一封已发出的日报，一屏一件，← 不想再看到 / → 还想看。存表 `radar_core.digest_item_labels`
   （迁移 `20261009230000_digest_item_labels`）。10-09 上午用本地页面标的 165 件已导入，并标为 Claude 已读。

## 用户标完以后 Claude 怎么做（"看下标注"）

用户不要自动化：他标，Claude 读、归纳、核对，他点头。

```sql
-- 没读过的「不想看」
SELECT p.name, l.title, l.price, l.source_id FROM radar_core.digest_item_labels l
JOIN radar_core.watch_profiles p ON p.id = l.watch_profile_id
WHERE l.verdict = 'hide' AND l.reviewed_at IS NULL ORDER BY p.name, l.title;
-- 核对用的「还想看」
SELECT title FROM radar_core.digest_item_labels WHERE watch_profile_id = '…' AND verdict = 'keep';
```

1. 把"不想看"的标题按"是哪一件商品"归堆，每堆写一条屏蔽（几个词格子，格子里 `|` 放别的写法）。
   零散的、认不出是哪件的不写规则——那是品类 / 年份偏好，跟用户说，不硬塞。
2. 每条规则用 `mutedProductTitleMatches` 跑一遍这个档案所有 `keep` 标题，**误伤必须是 0**；
   再看后台预演（过去 30 天会挡掉哪些）。宁松勿严：漏了下次再补，挡错了用户永远不知道。
3. 列给用户看（规则、能挡几件、误伤 0），他点头再写进 `watch_profile_muted_products`。
4. 读过的 `hide` 记上 `reviewed_at`：`UPDATE radar_core.digest_item_labels SET reviewed_at = now()::text WHERE …`。

## 没做的（之前讨论过）

- **年份 × 品类拦截**：屏蔽单品已经能写「2011 + フィギュア」，但不处理"标题里同时写几个年份就不拦"
  （「2011 2020 两个一起卖」「2010-2025」用户标了想看）。要专门做再说
- **跨平台同款合并**：拦完赛车初音还剩约 125 件，其中约 60 件是 2026 新周边在煤炉、乐天各出现一次，
  标题写法不同（【予約】【新品】… vs …／ホビーストック），同名折叠认不出。这是剩下的长度的大头
