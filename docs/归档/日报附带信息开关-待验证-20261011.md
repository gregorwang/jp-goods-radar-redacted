## 做了什么（一句话版）

关键词档案现在可以自己决定日报里每件商品下面附带哪几样价格参考：

- **原价**三选一：官方定価 + AI 预测（默认）/ 只要官方定価 / 不显示原价
- **同款成交**：开 / 关

关掉的部分**不再去请求**，不只是不显示：AI 预测关了，就让查价接口别估价（不启动收费的 Modal 显卡）；原价和成交都关了，整个查价接口都不调。

**赛车初音上新**已设成：不显示原价、保留同款成交。其他 4 个关键词档案都是全开，和以前一样。

```bash
ssh root@203.0.113.10 "sudo -u postgres psql -X -d jpgr" <<'EOF'
SELECT e.created_at, e.status,
  e.payload_json::jsonb->'digestExtras' AS extras,
  e.payload_json::jsonb->'enrichment'   AS enrich_meta,
  (SELECT count(*) FROM jsonb_array_elements(e.payload_json::jsonb->'items') i WHERE i ? 'enrichment') AS enriched,
  (SELECT count(*) FROM jsonb_array_elements(e.payload_json::jsonb->'items') i
    WHERE jsonb_typeof(i->'enrichment'->'estimate') = 'object') AS with_estimate,

FROM radar_core.events e
WHERE e.event_type = 'daily_digest' AND e.watch_profile_id = '27b5462c-612c-4ecf-8a8c-944e4c2c3f4f'
ORDER BY e.created_at DESC LIMIT 2;
EOF
```

## 出问题怎么办

- **赛车初音那封还有 AI 预测（`with_estimate` > 0）**：先查档案设置
  `SELECT digest_price_reference, digest_show_sales FROM radar_core.watch_profiles WHERE id='27b5462c-612c-4ecf-8a8c-944e4c2c3f4f';`
  设置对、载荷里 `extras` 也对、但仍有估价，就是对方接口没认这个标记：去 Cloudflare 看 teika-lookup 的日志，事件 `enrich` 里应有 `estimate_requested: false`。
- **日报没生成 / 有黄条**：按 `docs/常用/行情邮件未送达-排查手册-20260922.md` 分诊；采集程序日志搜 `digest_enrich_failed`。
- **要临时恢复成以前的样子**：把赛车初音改回全开即可，代码不用回滚：
  `UPDATE radar_core.watch_profiles SET digest_price_reference='official_and_ai', digest_show_sales=1 WHERE id='27b5462c-612c-4ecf-8a8c-944e4c2c3f4f';`
