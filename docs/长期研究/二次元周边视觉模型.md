## 要做的是什么

让看图模型更会认**二次元周边的同款**。两个地方都要用它：

1. **清单页 / 日报去重**：一堆商品图自己分组，同款合成一张卡（已经在用通用模型做，见研究文档）。
2. **精确同款雷达按参考图找货**：用户给一两张目标商品照片，每天拿新上架的图去比（另开会话研究，规则见研究文档"下一个用途"）。

通用模型在这几种情况下最弱，也是微调最该补的：

- **像但不是**：张嘴 / 闭嘴吧唧、普通 / 镭射吧唧、赞助特典版 / 市售版、1/7 / 1/8 比例手办。
- **不像但是**：官图 vs 卖家实拍、配件装了没装（初音 #563 #567 拿旗子 / 没拿旗子）、盒装 vs 拆盒。

## 微调是什么、训完怎么用（给不熟这块的人）

- **微调 = 拿现成的模型，用我们自己的标注再教它一阵**，改的是模型内部的参数，产物是一份新的模型文件（或者一个附在原模型上的小补丁文件）。
  不是从零造模型，现成模型已经会"看图"，我们只教它"二次元周边里哪些区别算数、哪些不算"。
- **要调的是"打指纹"那个模型**（现在是 DINOv2 + SigLIP），不是看图判断多件的那个大模型。
- **部署不用换平台**：现在这几个模型本来就是开源模型，跑在 Modal 上租的显卡里，每次用的时候加载。
  微调后只是把加载的模型文件换成我们自己那份，放在 Modal 的存储里，运行方式和花费基本不变。
- **训练本身也在 Modal 上跑**：几千张图的微调，租一张显卡一两个小时，估计几美元量级（到时候按实际再算）。

## 什么时候开训（10-08 讨论结论，10-09 补）

- **现在不划算**：明确标注才二十来条，"像但不是"太少，硬训只会背熟这几张图。
- **够用的量级**：几百款商品、每款 3 张以上不同卖家的照片，合计约 2000～5000 张；"像但不是"的例子几百对胜过几千张随便拍的。
  现在约 240 款 / 850 张，**再攒 3～4 封不同品类的档案**（手办、模型、卡牌混着的最好）。
- **标注方式**：系统先分组，人只做"拖出错的、合上漏的"。一封 1000 件的基线约 30～60 分钟。
- **必须留一部分永远不拿来训练当考卷**（白羽这封已定为考卷）。
- 样本可以自然攒：清单页以后加"这件不是同款"按钮，用户每点一次就是一条标注。
- 现成的"二次元专用模型"大多是拿插画训练的，而这里大部分是实物照片（盒子、手办），预计提升有限，不作主方向。
