## 1. 为什么要攒这个

- **对日报**：假货混进日报，就是一封「不该发的邮件」（AGENTS.md 第 4 节）。样本库攒起来，
  能变成判定里的一条**反证**，在邮件发出前挡掉明显的假签。

## 2. 按「怎么造的假」分类，不按作品分类

同一种造假手法会出现在很多作品上，按手法分才能变成规则。现有两条样本恰好是两类：

| 类型 | 说明 | 识别难度 |
|---|---|---|
| **A. 整件假** | 签名是假的，「认证」也是假的（比如仿评级卡盒子 + 不存在的认证机构标签） | 低：价格和认证机构就能判 |
| **B. 真货加假签** | 商品本身是真的日版（如一番赏色纸散货），手写签名是后加的 | 高：图看着都是真的，要知道「正品原本没有手写签名」 |

以后遇到新手法就往表里加一行（比如：复刻 / 仿制的整件盗版、印刷签名冒充亲笔等）。

## 3. 红线：做「识别手册」，不做「曝光黑名单」

- **只说商品，不点名卖家。** 写「这类商品出现以下特征基本可判为假签」，不写「某某店卖假货」。
  截图证明不了对方卖的那一件一定是假的，点名的诽谤风险全落在我们身上。
  （和探针执行文档 4.2 节已定的规则一致。）
- **公开前必须打码**：店名、水印（例：样本 1 图上的店铺水印）、**拼单栏里其他买家的昵称和头像**。
  后者是路人的个人信息，和卖家无关。
- 结论要有数字出处，可核对（同「邮件按给大众看的标准做」）。

## 4. 识别特征（初稿，靠样本验证）

| 特征 | 代码能不能判 | 备注 |
|---|---|---|
| 标价远低于正品二手成交价（例：不到 5%），**同时**标题自称「亲笔 / 保真 / 签名」 | **能**。我们有 jp-market-databricks 的成交行情，这是别人没有的优势 | 阈值等样本够了再定，别凭直觉 |
| 同一「亲笔签名」卖出几十上百件 | 能（如果平台展示销量） | 真亲笔不可能批量 |
| 「认证」来自不存在 / 查不到的机构 | 半能：可维护一份认证机构名单 | |
| 正品原本不带手写签名（如一番赏色纸），图上却有 | 难：要知道正品长什么样 | 可借参考图找货那套比对，以后再说 |

按 AGENTS.md「把代码有把握的事做厚」：第一条是确定性的，代码做；「到底是不是假」的最终判断交给 AI，
并把 AI 的表态落库参与判定。

## 5. 记录格式

每条样本记一行，截图文件名对上：

| 字段 | 填什么 |
|---|---|
| 编号 / 日期 | |
| 截图文件 | `png/` 下的文件名 |
| 平台 | 拼多多 / 闲鱼 / 煤炉 / 雅虎拍卖 …… |
| 标题原文 | |
| 冒充的正品是什么 | 作品、角色、品类、被冒签的人 |
| 类型 | A 整件假 / B 真货加假签 / 新类型 |
| 假在哪里 | 一两句，写具体证据 |
| 标价 | 原币种 + 金额 |
| 正品参考价 | 二手成交价，写出处；查不到写「无」 |
| 销量 | 平台显示的已售 / 已拼件数 |
