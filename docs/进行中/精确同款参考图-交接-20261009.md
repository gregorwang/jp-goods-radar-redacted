**分流规则的落地方式（不新造状态）：**
- 标题对上 + 图对上：事件照常进这一轮日报，邮件里标题下多一行"商品图与参考图一致（N 个细节点对上）"。
- 标题没对上（`uncertain`）+ 图对上：改判 `confirmed`、登记匹配（`acceptance_reason='image_reference'`）、建上新事件，跟这一轮日报一起发，注明"标题没能确认，但图和参考图一致"。
- 标题对上 + 图没对上：事件打上 `deliveryHold:image_mismatch`、`delivery_not_before`=下一个北京 21:00；早上的日报跳过它，晚上单独一封"N 件标题判为同款、但商品图和参考图不同"。白天卖掉的不发。
- 标题没对上 + 图没对上：仍 `uncertain`，`image_verdict='mismatch'`，理由写"图也不同"；放宽了送达门槛的档案也不再把它当疑似发。
- 「〇〇様専用 / さん専用 / 専用出品 / 専用ページ」：改判 `rejected`，事件 `suppressed`。「専用ケース」这类配件说明不算。
- 同一件、同一张图、同一组参考图打过分的复用旧分数，不再开机；换了参考图自动重算。
- 开关关着 / 档案没参考图 / Modal 失败或 150 秒没算完：整段跳过，和以前完全一样只看文字。

**已知的限制：**

## 1. 用户已拍板（10-09）

1. **参考图由用户给**，不自动拿系统确认过的图。精确同款建档页加"参考图（可选）"上传框（1～2 张）；**已建好的档案也要能补传**。没传参考图的档案照旧只看标题，不走图片。
2. **只看漏斗筛剩的**：图片模型不碰每天全部约 200 件候选，只看漏斗下来的——AI 拿不准的（`uncertain`）、标题或 AI 认为对上的（`confirmed`）。每次几件到十几件。
3. **「〇〇様専用」直接排除**：给特定买家留的货，别人拍不了。不送图片、不发。
4. **发送规则**：

   | 标题（现有文字判定） | 图片 | 怎么发 |
   |---|---|---|
   | 对上 | 对上 | **马上发** |
   | 没对上 | 对上 | **马上发** |
   | 对上 | 没对上 | **攒到晚上统一发一封**（暂定北京时间 21:00 = UTC 13:00；用户："白天要做别的事，挑个垃圾时间发"） |
   | 没对上 | 没对上 | 不发 |

   - "标题对上、图片没对上"包括 09-05 / 09-13 那种 **AI 把 Fes. Fine 判成同款**的情况——晚上那封里要写清"标题判同款，但商品图和参考图明显不同"。
   - **未定**："标题明确写着另一个版本（制服 Ver.）、图片又很像"归哪格，用户说**看数据**（"制服和浴衣肯定不一样，我试过"）。先按"对上就马上发"做，上线后看数据；要一张制服款的图另测（几分钱）。
   - "标题没对上"在这里指漏斗里 AI 拿不准的那批。漏斗第一层就被判"无关"的（标题一个身份词都没有）不进图片模型——用户 10-09 确认不需要（"専用那种肯定排除"）。
5. **门槛跑数据定**，这是单件商品对参考图打分，不是去重分组。初始值见 §3。
6. **一定要先降成本**：指纹和细节比对合进一台机器、模型只装一次、算完马上关（单次 $0.03 → $0.005）。
7. **要有开关**：链路全部搭好，开关关着就完全不调用 Modal（$0）；下个月用户"按一下"就接通，不用改代码、不用部署。

## 3. 门槛初始值（10-09 实测，7 个档案里能测的 7 个）

**看"细节点"为主、"整体相似度"为辅。** 细节点 = 两张图上能一一对上、位置关系也对得上的小地方的个数。

| 档案 | 真品 | 最像的非真品 |
|---|---|---|
| 爱蜜莉雅毛绒（用户参考图） | 0.91～0.97 / **150～1213 点** | 0.88 / **≤69 点** |
| 初音浴衣色纸：官图 vs 用户给的闲鱼实拍（装袋、反光、水印） | 0.89 / **1046 点** | 0.69 / **≤49 点** |
| メダリスト展 画册 | 0.83～0.94 / 479～1740 | — |
| 冴えカノ♭ プリモアート | 0.69～0.99 / 238～1781 | Fes. Fine 0.55 / 14 点 |
| アゾン 1/6 エミリア | 0.88～1.00 / 190～382 | 同系列别版 0.82 / 54 |
| 高木 T 恤（叠起来 / 装袋拍） | 0.71 / **59～62 点** | 灰色外套 ≤0.78 / ≤22 |
| WHITE ALBUM2 毛绒 | 0.82～0.97 / **31～140 点** | ≤0.64 / ≤15 |

建议起步：**细节点 ≥100 = 图片对上**；**整体相似度 ≥0.90 且细节点 ≥30 也算对上**（接住毛绒）；其余算没对上。
衣服叠起来拍（59～62 点）会算没对上——按发送规则它若标题对上就晚上发，不会丢。上线后用"已售同款"（`来源状态 sold_out` 且标题对上的，免费的真品样本）回测调整。
